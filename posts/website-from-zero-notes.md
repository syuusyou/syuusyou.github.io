在還沒有任何程式基礎之前，我一直好奇：「從電腦裡什麼都沒有，到做出一個別人輸入網址就能看到的網站，中間到底發生了什麼事？」今天我終於親手把它走完了一遍，特別寫下這篇筆記當作紀念！

## 1. 網頁的三大基石 + Markdown 文章資料夾

原來瀏覽器看到的每一個網站，背後都是由幾個核心角色組成的：

- `index.html`：負責網站的**骨架與結構**（導覽列、搜尋框、文章容器）。
- `style.css`：負責網站的**外觀裝潢**（溫柔的配色、字體間距、手機版自動排版、還有右上角的深淺色模式！）。
- `posts/*.md`：現在每篇文章都獨立存放在 `posts/` 資料夾底下，用最簡潔的 **Markdown (`.md`)** 格式撰寫，管理起來超輕鬆！

## 2. 用 Git 幫網站拍下「時光機快照」

工程師在寫網站時都會用一個叫 `Git` 的工具。每次新增一篇 `.md` 文章，只要執行 `git commit`，就像在遊戲裡存檔一樣，隨時可以回到過去的版本，還能把程式碼推送到雲端的 GitHub 倉庫妥善保存。

## 3. 雲端主機與專屬獨立網址

檔案放在自己電腦裡只有自己看得到；透過把 GitHub 連動到免費的雲端主機（像是 Cloudflare Pages），再綁定自己專屬的獨立網址（Domain），全世界的人就都能隨時隨地連進「咻咻的心情隨筆」了！
